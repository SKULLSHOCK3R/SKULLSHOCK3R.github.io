Home JARVIS

Home JARVIS is a private home automation setup for a single household. It connects the owner's own Google Nest devices (a doorbell, a porch camera and a thermostat) to the owner's own Home Assistant system, which runs on the owner's home network.

It uses Google's Smart Device Management API so that the owner can see doorbell and motion events, view camera streams on demand, and read the thermostat from Home Assistant.

Home JARVIS is not a public service. It has no sign-ups and no user accounts, and it is not available to anyone other than its owner. It does not access any Google account or device other than the owner's own.

Read the Privacy Policy for details on what data is accessed and how it is handled.
