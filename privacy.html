H.I.V.E. Privacy Policy

Effective date: 2026-10-13

Back to the homepage

1. Who this applies to

H.I.V.E. is a private, single-household home automation setup. It is operated by its owner for the owner's own use and is not offered to the public. It has no sign-ups and no other users. This policy explains how the setup handles the data it accesses from Google.

2. Data accessed

H.I.V.E. accesses data only from the owner's own Google account and the owner's own Google Nest devices, and only with the owner's consent. The data is:

  • Nest device information, such as device names, types and status.
  • Camera live streams from the owner's doorbell and porch camera, viewed on demand.
  • Doorbell and motion event notifications.
  • Thermostat readings and settings.

3. How the data is accessed

Data is accessed through Google's Smart Device Management API. Event messages, such as a doorbell press or motion, are delivered through Google Cloud Pub/Sub.

4. How the data is used

The data is used only to provide the user-facing features of the owner's own Home Assistant: showing device status, showing camera streams, recording an event history and sending notifications. In keeping with the spirit of the Google API Services User Data Policy, including its Limited Use requirements, this data is used only to provide those features to the owner. It is not used for any other purpose.

5. Where the data is processed and stored

The data is processed and stored only on the owner's own Home Assistant system, which runs at the owner's home. Event history is kept there. Notifications are sent to the owner's own phone through the Home Assistant companion app, which delivers them using its standard push notification service and the phone platform's push service.

6. Sharing

The data is not sold, shared or disclosed to anyone. It is not used for advertising or analytics. It passes only through the services needed to run the features above: Google's own services, which carry the data between the owner's Nest devices, the Smart Device Management API, Google Cloud Pub/Sub and Home Assistant, and the push notification services that deliver notifications to the owner's phone.

7. Retention

Data is kept on Home Assistant according to its history and retention settings, until the owner deletes it.

8. Revoking access

The owner can stop H.I.V.E.'s access at any time in any of these ways:

  • In the Google Account security settings, remove H.I.V.E. from the list of third-party apps and services with account access.
  • In the Nest app, remove the H.I.V.E. partner connection.
  • In Home Assistant, remove the Google Nest integration.

9. Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date. Effective date of this version: 2026-10-13.

10. Contact
