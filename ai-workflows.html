AI Workflows

Two coding assistants work from the same rules: J.A.R.V.I.S. on Claude Code and E.V. on Codex. This page describes my own setup. The open-source starter kit (MIT licence) packages the same rules, and in it the hooks and the multi-stage workflow are optional. View the starter kit on GitHub.

What it does

A single rulebook (AGENTS.md, with a byte-identical CLAUDE.md) governs both assistants, so the same rules apply whichever one picks up a task. Any non-trivial task is split into stages, each run as a new AI session that starts with no memory of the conversation (fresh context) and gets only a short written brief. The last stage is always a separate, independent review.

How I built it

  • My setup: startup checks. Two Claude Code hooks (small scripts that Claude Code runs automatically at set moments) support the rulebook. At session start one checks that the core rule files are present and that the two rulebook copies are identical, then prints a short manifest that stays under Claude Code's 10,000-character hook limit. The other re-attaches a short persona summary to each message. In the starter kit, hooks are optional.
  • My setup: staged work. Planning, production and independent final review run as separate fresh-context stages. There are six stage roles across three model tiers. A strict quick-task test may skip planning, but never the review. In the starter kit, the multi-stage workflow is optional and proportional to the task.
  • Approval guardrails. Each paid call needs its own yes, with a cost estimate and a ceiling. Outgoing messages need approval of the exact text and recipients. Instructions found inside emails or web pages are treated as data, not commands.
  • Safe change handling. Commit before editing, no history rewriting, backups checked by file fingerprint (SHA-256), and a recovery protocol for a stage that is cut off part way.
  • File intake. New files are checked for stability with SHA-256 and archived only after an approval.
  • Memory. Dated, scoped lessons record corrections so the same mistake is not repeated.
